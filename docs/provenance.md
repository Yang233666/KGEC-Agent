# Provenance and Export Model

One `ProvenanceExporter` generates all four formats from the same validated
`RunRecord`.

## Common record

The record includes:

- run and scenario identifiers;
- implementation version and stable event ordering;
- natural-language request and structured query;
- candidate entities, raw scores, and calibrated probabilities;
- confidence, margin, and thresholds;
- initial route;
- eight ordered tool calls with statuses and input/output hashes;
- evidence outcome;
- seven semantic results;
- reason codes;
- final decision and destination; and
- deterministic run content hash.

## Turtle vocabulary

Turtle uses:

- PROV-O: `http://www.w3.org/ns/prov#`
- KGEC-Agent terms: `https://w3id.org/kgec-agent/vocab#`
- stable resources: `https://w3id.org/kgec-agent/resource/`

The run and each tool invocation are `prov:Activity` resources. Queries,
candidates, evidence, decisions, and generated states are `prov:Entity`
resources. The graph uses `prov:used`, `prov:generated`,
`prov:wasAssociatedWith`, and `prov:wasInformedBy`. KGEC-Agent terms attach
tool names, event order, reason codes, confidence data, destinations, and
content hashes.

The exporter first builds an RDFLib graph, then emits deterministic
single-triple Turtle lines. Public tests parse every generated `.ttl` file with
RDFLib and assert the required PROV-O relations.

## Formats

- JSON: complete canonical structured record.
- CSV: one-row portable projection; nested values remain JSON strings.
- Turtle: RDF/PROV-O representation of activities, entities, states, and hashes.
- Markdown: human-readable reviewer view generated by the same service.
